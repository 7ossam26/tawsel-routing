# Confirmed locations and self-hosted maps — Phase 11

Implemented locally, 22 September 2026. [Evidence and limitations](phase-11-evidence.md), [canonical schema](../contracts/location.schema.json), [operation coverage](contract-coverage.md), [asset manifest](../maps/manifest.json).

## Try the connected flow

Use the supported Node 24/npm 11 environment from [operations](operations.md). Start the dedicated database and apply additive migration 0008 with `npm run db:local:start` and `npm run db:migrate`. Normal application login continues to use P07 Keycloak/session configuration. Configure a **private, already provisioned** Nominatim with `TAWSEL_NOMINATIM_URL=http://127.0.0.1:8080/`. Application setup does not start or import it. No public geocoder fallback exists.

Explicitly prepare maps once: `powershell -NoProfile -File scripts/maps-prepare.ps1`. This downloads the pinned PMTiles CLI, verifies its SHA256, extracts a Cairo region, verifies the archive SHA256 and structure, then obtains pinned glyph/sprite assets. It never touches Engine datasets/mounts. Existing local assets are reused after verification. The upstream daily archive may expire: retain the provisioned `.local/maps` bundle with the manifest, or retain that exact planet build at a controlled mirror and pass `-ArchiveSource`. A newer build requires an explicit new manifest/review; it must not silently replace the verified release.

Run `npm run dev`. Personal account → **مهام التوصيل** → add/save an address → **مراجعة الموقع**. Search, choose a candidate or a point, then **تأكيد نقطة التوصيل**. Keyboard users can pan the map with arrows and use **اختيار وسط الخريطة**; numeric coordinate entry works when WebGL/assets fail. Map movement and candidate selection remain drafts until confirmation. Company account → **مراجعة مواقع المهام**, or `/locations?kind=company`; the first 50 authorized tasks are shown. Direct links `/locations/{taskId}?kind=company` support other known authorized tasks. This is a focused review surface, not the complete P28 preparation journey.

For a reproducible isolated demonstration without touching account data, run `npm run locations:demo`, then in another terminal set `VITE_TAWSEL_API_BASE_URL=http://127.0.0.1:3011` and run `npm run dev -w @tawsel/web -- --host localhost --port 5177`. Open `http://localhost:5177/tasks`. The demo uses **fixture principals and candidate responses**, real isolated PostgreSQL, real HTTP APIs and real local maps. Search `فارغ` for empty results or `فشل` for controlled failure. Ctrl+C closes/removes the isolated database. Do not expose this harness publicly.

## Authority and revisions

- Source address/pin remains in P09 intake or immutable P10 source snapshots. Confirmations write `task_locations`, append-only `location_history`, and the P05 command audit/result in one transaction.
- Browser session kind is explicit. An ERP bearer credential is not a human reviewer. `location.review` grants staff access within their assigned branches. Drivers require own execution/correction authority and actual assignment. Guessed tenant/task IDs never select a different scope.
- Search uses the private Nominatim JSONv2 endpoint with Egypt country/bounds, 5 results, 4-second timeout, 256KiB response ceiling, 8 concurrent requests, 128 cache entries and five-minute expiry. Tokens bind tenant/account/task/source revision. They are suggestions, with source/type/context, and no match percentage. Cache eviction/restart requires another search or manual selection.
- Confirmation requires `confirmed=true`, current `expectedSourceRevision` and `expectedLocationRevision`, and either a scoped candidate token or named finite latitude/longitude. Global bounds are latitude −90…90 and longitude −180…180. Display-map coverage is a separate restriction, visibly reported.
- Successful confirmation increments location revision and the assigned driver's planning-input revision, stores a pending replan intent and (B2B) a source-scoped `location.pinConfirmed` outbox intent. **No plan is calculated or published.** The receipt exposes separate source/location/planning-input versions. P13 must consume both source and location revisions; a changed source invalidates an older confirmation. Existing source-confirmed input has location revision 0 and explicit `source-confirmed` provenance.
- B2B held/eligible confirmations reserve a remaining stop under the shared driver/task locks; exceeding 50 including branch visits rolls back all tentative confirmation/replan/history writes. Prepared work stays prepared. Unresolved work does not block unrelated valid work.
- Staff edits are rejected after `departure_at`; the assigned driver with `correction.own` may correct afterward. **P15 still must implement and prove actual departure/start races** using the same invariant locks. Current tests use persisted departure fixtures, not a real started round.

## Map bundle, coverage and licenses

The real archive is `.local/maps/cairo.pmtiles`, **45,260,921 bytes**, derived from `https://build.protomaps.com/20260922.pmtiles` using go-pmtiles 1.31.2. SHA256 and all font/style/sprite/RTL hashes are in [manifest.json](../maps/manifest.json). Requested bounds: west 31.0°, south 29.8°, east 31.65°, north 30.3°. Tiles cover whole tiles intersecting those bounds; this is **Greater Cairo**, not Egypt-wide coverage. Stored zooms 0–15; higher UI zooms overzoom existing detail up to 18. No building entrance accuracy or road-routing guarantee is implied. Coverage outside the region requires another explicitly provisioned archive.

MapLibre 6.10.0, PMTiles JS 4.5.0, Protomaps style 5.7.2 and RTL 0.4.0 are pinned. Noto Sans Regular glyphs (all 256 BMP ranges, including Arabic/presentation forms), light sprites at 1x/2x, the local RTL/ICU plugin, generated Arabic style and Vite-bundled worker are all served locally. Unsupported non-BMP glyph coverage is not claimed. Runtime records show no remote asset requests. Route geometry remains a distinct future layer.

Licenses/notices: [MapLibre BSD](licenses/MapLibre-BSD.txt), [Protomaps BSD](licenses/Protomaps-BSD.txt), [data/source attributions](licenses/Protomaps-Data.md), [Noto OFL](licenses/Noto-OFL.txt), [MIT icon sprites](licenses/Tangram-Icons-MIT.md), [RTL/ICU](licenses/RTL-ICU-LICENSE.md). OSM-derived data is an ODbL produced work; Natural Earth is public domain; landcover attribution includes ESA WorldCover (CC BY 4.0). Local changes select Arabic labels and use one fontstack. Preserve attribution and notices when distributing the bundle. PMTiles tool/library licensing remains in their pinned distributions.

Fastify serves `/maps/*` from the configured `TAWSEL_MAP_ASSET_DIR` (default `.local/maps`), with an asset allowlist, `Accept-Ranges`, 206 `Content-Range`, bounded byte ranges and 416 invalid ranges. Missing configured assets return 503. The [Nginx example](../maps/nginx.conf) mounts the same bundle for deployment; no production proxy/deployment has been verified. Keep archive, style, sprites, glyphs, worker and RTL assets from one release together; cache max-age is one hour. No compression of PMTiles is allowed at the proxy.

## Failure behavior and verification

Search error/empty results preserve original input and current pin. Tile/worker/WebGL failure leaves the task details, map-failure message and numeric confirmation usable. Draft query/selection and an uncertain exact action persist in account/task-scoped session storage; retries reuse that action. Reload-current is explicit for stale revisions. This is not P33 durable offline delivery capture.

`npm run test:locations` runs real PostgreSQL authorization/revision/rollback plus controlled geocoder HTTP scenarios. `npm run test:browser:locations` uses actual Chromium, HTTP, PostgreSQL and local map assets; its session/candidate seams are fixtures. Set `TAWSEL_MAP_PRODUCTION_CHECK=1` after the web build to run the same browser scenario against production preview. `npm run check` covers repository checks. Browser touch is emulated; Android/iPhone hardware, owner UX review and live private Nominatim are outstanding. The local Nominatim status probe refused connection; no import was attempted to manufacture a live-provider pass.

Phase 12 may rely on confirmed named coordinates, original/source provenance, location/source revisions, scoped reads, atomic pending planning invalidation, source-scoped event intent and verified local map serving. It must independently verify Engine routing profiles/units/geometry. P13 planning completion, P15 departure, P25 signed delivery, P28 full preparation and P41 physical-device/owner validation remain separate phases.
