# Audit corrections and reproducible publisher identity

Owner selected all 2026-10-11 integration audit corrections. Historical publisher declarations remain verbatim under `historical-2026-10-10/`; Shahn also retains the original publisher ZIP under its fff79bc baseline. Those raw hashes and the four disclosed source mismatches are historical evidence, not silently repaired claims.

The corrected publisher uses **git-blobs-v1**: source/config/tests are committed first, and their exact immutable Git blob bytes are hashed. `baseCommit` identifies that source revision. Checkout CRLF filters do not redefine raw hashes. Packaging copies source artifacts from that commit and independently hashes all generated artifacts. A later descendant documentation/proof commit is legitimate only when the source inventory and hashes remain identical. Uncommitted source changes, inventory drift, unrelated history, generated artifact drift, missing/stale consumer proof and changed tracked package inputs fail verification.

Functional corrections bind monitoring activity to its original task **and attempt**, and bind retained outcome/current/eligibility/correction recovery to immutable attempt/cycle scope. Accepted audit and rejected envelope evidence survive response compaction; legacy summaries fall back to original admissions with fail-closed authorization. Current B ownership cannot authorize an A response. Correction availability and eligibility history use the same frozen attempt scope. Duplicate relocation lines and inconsistent exact totals are rejected before persistence; relocation preserves the original complete line set and captured unit prices.

Regression fixtures execute A heading/arrival/refusal/correction, actual A return receipt, B redispatch, the same driver and round, A-only/B-only/both staff scope, direct action reads and pagination, retained full/compacted/legacy/rejected command recovery. No permissions are widened and original results/evidence remain immutable.

The isolated suite bounds concurrent workers to two.
